### Key cross-cutting observations

1. **Google widgets take the head of the "random/time" cluster.** Stopwatch, timer, coin flip, dice, spinner, RNG and metronome all show an interactive Google widget first. Click-through on these head terms is poor. The organic clicks go to **long-tail and feature-rich variants**: "flip a coin 100 times", "coin flip simulator", "d20 dice roller", "random team generator", "yes or no wheel", "pomodoro timer", "10 minute timer with alarm".
2. **Hardware and device test tools (keyboard, mic, webcam, dead pixel, mouse, gamepad, left/right audio, CPS, spacebar) are the best opportunity in this category.** Page 1 is mostly **small exact-match or indie sites** (keyboardtester.click, mictests.org, testmyinput, devicechecker, deadpixeltest.org, cps-check.com, clickspeedtest.io), plus Loom for webcam/mic. They run 100% client-side (KeyboardEvent, getUserMedia, Gamepad API, Web Audio, fullscreen canvas). Users return (gamers, remote workers), and several are US/UK/CA-heavy (Zoom/Teams mic checks, gaming).
3. **Security tools (password generator, strength checker) sit on security-brand SERPs.** 1Password, Bitwarden, NordPass, LastPass, Norton, Kaspersky and Keeper all run password generators as funded lead-gen. A new domain will not reach the top 5 for "password generator" within 6 months. Long-tails can be won: passphrase, PIN, "password generator 16 characters", "password generator without special characters", "memorable password generator". Keep the head page for topical authority and internal linking. The security audience brings high CPC.
4. **PDF tools are brand-dominated** (Adobe, iLovePDF, Smallpdf, Sejda, PDF24, Foxit, 11zon). For a new domain the angle is **"no upload / processed in your browser / private"** plus long-tails ("merge pdf without uploading", "rotate pdf and save", "delete pages from pdf", "pdf page counter"). Compressing PDFs client-side is weak (you can only rasterise or re-encode images with pdf.js plus canvas), so hold it for the roadmap.
5. **QR:** the "qr code generator" head term (538K US [A]) sits with a funded incumbent (qr-code-generator.com, Canva, QR TIGER, Bitly). **WiFi QR, vCard QR and QR scanner-from-image** have thin SERPs (qifi.org, a tiny static page, ranks), and they suit a new domain better. image-media.md owns the main QR generator. This file owns the scanner and the WiFi/vCard variants. **De-dupe at planning time.**

## 2. AdSense / ToS risk review for this category

| Tool idea | Risk | Decision |
|---|---|---|
| Receipt maker / receipt generator | **High.** The "Enabling dishonest behaviour" policy covers fake documents. Receipt makers are widely used for expense fraud. Also on the project's hard-exclusion list. | **EXCLUDE** |
| Fake name / fake identity / fake address generator | Medium to high (fake identity). | **EXCLUDE** |
| Credit card number generator (Luhn test numbers) | **High** (carding/fraud connotation, even when framed as "test numbers"). | **EXCLUDE** |
| Lottery number generator / "lucky numbers" | Medium to high. Gambling-adjacent: AdSense restricts gambling content and would limit or disable ads. | **EXCLUDE.** Use a neutral "random number generator" instead (owned by converters). |
| MD5 / SHA "decrypt" or "hash cracker" | Medium to high (hacking tool, and it needs a lookup DB anyway). | **EXCLUDE** |
| Unlock PDF / remove PDF password or restrictions | Medium (seen as bypassing document protection or DRM). | **EXCLUDE at launch.** A future "remove password from a PDF you know the password to" is possible but not worth the risk. |
| Temp mail / disposable email / URL shortener / proxy | High (abuse, needs a server). | **EXCLUDE** |
| 2FA / TOTP code generator (2fa.live-style) | Medium. The niche is heavily used by social-account farming and resellers. | Roadmap only, framed as a developer testing tool. Not at launch. |

| Screen recorder / voice recorder | Low. Do not mention recording streams, DRM video or other people without consent. | OK |
| Wheel / coin / dice / bingo | Low. Avoid "betting", "casino", "raffle for money" framing. Classroom/teams framing is safe. | OK |
| What is my IP | None. | OK (server-light) |

### 5.1 Password Generator
- Long-tail: password generator · random password generator · strong password generator · secure password generator · password generator 12 / 16 / 20 / 32 characters · password generator without special characters · password generator with symbols · memorable password generator · easy to remember password generator · wifi password generator · bulk password generator · password generator no repeating characters · password generator online free · google password generator (brand intent: explain Chrome's built-in one).
