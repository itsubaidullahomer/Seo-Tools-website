## 0. Method and caveats

- All evidence came from live WebSearch (about 65 distinct queries). WebFetch was blocked by the environment egress proxy for every third-party domain tried (seodata.dev, semrush.com, ahrefs.com, seranking.com, technicalseo.com, smallseotools.com, ahrefstop.com, thestackanalyst.com, reddit.com), so competitor pages could not be read directly. Volumes below therefore come from (a) figures that appeared verbatim in search snippets (Semrush "website overview" pages, seodata.dev keyword pages), (b) competitor traffic figures that appeared in snippets, and (c) labelled estimates triangulated from those, from the number/quality of competing tool pages, and from autocomplete-style variants seen in result titles.
- Every volume is a RANGE. "Semrush snippet" and "seodata.dev snippet" figures are the only hard numbers; everything else is marked "estimate".
- Google/AdSense state as of Sept 2026 that matters for this category is summarised in section 4 (FAQ rich results dead since 7 May 2026; HowTo dead since 2023; Google's Mobile-Friendly Test dead since Dec 2023; GSC robots.txt tester replaced by a report in 2022-2023; X/Twitter Card Validator effectively gone; Google testing AI title rewrites since March 2026).

## 3. Competitor observations

- Head terms in this category are dominated by three tiers: (1) Google itself (Campaign URL Builder, Rich Results Test, schema.org validator), (2) big SEO SaaS free-tool hubs that now publish a free tool for nearly every keyword (Semrush /free-tools/ incl. SERP Simulator, Sitemap Generator, Keyword Density; Ahrefs sitemap generator + writing tools; SE Ranking free tools incl. title/description checker, robots.txt generator/tester, keyword density; Rank Math tools; Mangools SERP simulator; Keywords Everywhere's 44 free tools incl. schema generator, title length checker, robots.txt generator with AI-bot blocks; Backlinko keyword density; Elementor tools), (3) legacy tool farms (smallseotools 3M/mo, prepostseo 150+ tools, seoptimer 600-800K/mo, sitechecker.pro 740K/mo, seositecheckup, dnschecker, rapidtables, seobook).
- Single-purpose micro-sites still win big on specific terms: xml-sitemaps.com (714K), slugify.online (290K), metatags.io (222K), opengraph.xyz (~300K), utmbuilder.net (73K), highervisibility SERP snippet optimizer, aleydasolis hreflang generator, danielmorell htaccess generator, technicalseo.com (Merkle) schema generator + robots.txt tester + SERP simulator. Their traffic is heavily DIRECT (60-65%) which signals bookmarking/repeat use: build for repeat use (remember last inputs in localStorage, keyboard-friendly, copy buttons).
- Audience geography for these tools skews India / Indonesia / Pakistan / Philippines plus US. UTM builder is the exception (US 36%, high CPC $15.56) and is therefore the best AdSense-RPM tool in the set.
- 2026 trend: a wave of brand-new small sites (nuxtseo.com tools, serp.tools, wildandfreetools, lettercounter.org, gizmoop, seoscore.tools, ranklogs, iloveschema, aicrawlercheck) are publishing 2026-dated long-form guides + tool combos on exactly these long-tail terms and ARE appearing on page 1 for them. That is direct evidence the long-tail (length checkers, robots.txt AI-bot blocking, llms.txt, OG image size, twitter card validator replacement, schema validator) is winnable for a new domain.
- Keyword Everywhere's robots.txt generator differentiates with one-click "block AI training crawlers"; aicrawlercheck.com has 248+ bot presets. This is the current differentiator for robots.txt tools.
- Schema generator market leader (technicalseo.com/Merkle) still uses the classic type-list UI; competitors add live validation, "copy to Rich Results Test" links, and 50+ types (iloveschema). JSON-LD Generator (jsonld.com) shipped v2.0 in April 2026 with live required-field validation for 17 types.
- Title/description length checkers now compete on PIXEL width (600px title desktop, 920px description desktop, ~580px mobile) and on 2026-dated guides. Bulk-URL mode (SE Ranking) is server-side; paste mode is client-side.

## 4. Google / AdSense state (Sept 2026) that affects tool design and content

- FAQ rich results: removed for all sites on 7 May 2026 (had been restricted to gov/health since Aug 2023). FAQPage remains valid schema.org, no need to remove, but no SERP benefit. -> Do not lead the schema tool with FAQ; keep it as a type but say so in content.
- HowTo rich results: gone since 2023. Google retired seven structured-data features in June 2025 (Course info, Claim Review, Estimated salary, Learning video, Special announcement, Vehicle listing, Book actions was later re-confirmed as supported) and Practice Problem in Jan 2026. ~31 types still have rich-result support as of March 2026; Product, Organization (+ merchant listings), Article, BreadcrumbList, LocalBusiness, Event, Recipe, VideoObject, JobPosting, Review snippet, Person/Profile page, Dataset (Dataset Search only) are the safe set.
- Google confirmed (20 March 2026) it is testing AI-generated title rewrites; earlier studies: Google rewrites 33% (Ahrefs) to 61% (Zyppy) of titles, 77.6% when the title contains brackets. Good content angle for SERP preview / title checker pages.
- Title length: ~600px desktop (~50-60 chars). Meta description: ~920px desktop (~155-160 chars), ~580px mobile (~120 chars); Google rewrites ~30-35% of descriptions. Pixel-based checking is the expected feature.
- Google Search Console: robots.txt Tester removed (announced 2022, replaced by robots.txt report in 2023); Mobile-Friendly Test + API + Mobile Usability report removed 1 Dec 2023 (Lighthouse recommended). Third-party iframe-based "mobile friendly" checkers fail on most sites due to X-Frame-Options/CSP -> infeasible for us.
- X/Twitter Card Validator: preview removed 2022, intermittently broken, now login-gated and unreliable; no official replacement in 2026 -> real gap, but a URL-based validator needs a server fetch (server-light roadmap). A paste-your-meta-tags preview is client-side.
- Structured data testing: Google's Structured Data Testing Tool retired; Rich Results Test + validator.schema.org are the official tools; many third-party validators exist.
- UTM: GA4 has 8 parameters (utm_source, utm_medium, utm_campaign, utm_term, utm_content + utm_id, utm_source_platform, utm_creative_format). Google states UTMs do not affect rankings; canonical tag handles duplicates.
- Sitemaps: 50,000 URLs / 50 MB uncompressed per file; sitemap index up to 50,000 sitemaps; News sitemap 1,000 URLs.
- robots.txt: crawling not indexing; Google ignores Crawl-delay (Bing/Yandex honour it); must live at domain root; AI crawler UAs commonly handled in 2026: GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, anthropic-ai, PerplexityBot, Google-Extended, CCBot, Bytespider, Amazonbot, Applebot-Extended, meta-externalagent. Cloudflare data (Sept 2026): publishers block GPTBot 2.3x more than they allow it, but allow OAI-SearchBot.
- llms.txt: emerging convention ("robots.txt for AI"); many 2026 SaaS generators (Writesonic, Mintlify, SiteSpeakAI, LLMrefs, Gushwork, context.dev, llmstxtgenerator.co). Not a Google feature; be honest in content that adoption by AI vendors is unconfirmed.
- AdSense 2026: enforcement focuses on "low value content" (thin, templated, unedited AI). Tool pages need substantial original, helpful text (the project's 1000+ words rule covers this), trust pages (about/contact/privacy), HTTPS, mobile. Nothing in this category touches restricted content. Only soft risks: tools that facilitate link spam ("backlink maker", "anchor text generator" framed for spam) and tools that scrape Google (rank checker, index checker, Google-suggest scrapers) which are ToS problems rather than AdSense policy problems. None recommended.
